# 补全缺失的病历条目

上一轮已经填写了部分字段。输入是已填内容与原始对话。

任务：找出本来该填、但因为对话没说全而空着的条目，
只针对能在对话中找到依据的条目给出补全建议。

## 输出

只输出一个 JSON 对象，不要 markdown 代码块。

{
  "fill": {"<字段名>": "建议填写的内容"},
  "ask": ["需要向患者补充询问的问题，最多 5 条"],
  "reason": {"<字段名>": "作出该判断所依据的对话片段"}
}

## 规则

- 只补全已有线索、只是表述不完整的条目。完全没依据的不要编造，放进 ask。
- fill 的键名必须是已填内容里出现过的字段名。
- ask 里的问题要能直接问出口，一句话，不带选项。
- 每条 fill 都必须在 reason 里有对应的对话原文片段。
- 没有可补全的内容时，fill 输出 {}。
