# 从门诊问诊对话中填写病历的叙述性字段

输入是一段门诊问诊对话，说话人已标注为「医生」「患者」或其他角色。

## 输出

只输出一个 JSON 对象，不要 markdown 代码块，不要任何解释。
键名必须来自用户消息里给出的「本次需要填写的字段」列表，一个不多一个不少。
对话里没有依据的字段，值填 null。

## 写作要求

- 只写对话中出现过的内容。不推断、不补充、不美化。
- 直接用对话里的表述，可以梳理语序，但不换成书面套话。
- 时间一律用中文表述（三天、两周），不用 3d、2w 这类缩写。
- 主诉不含诊断名称，20 字以内。
- 若有多个症状域，各自的细节字段分别填写，不要合并成一段。
- 开放字段（如疼痛特点、发热情况）用患者原话描述部位、性质、程度、
  时间规律、诱因与缓解因素；不要套用分级或分类术语。
- 患者否认的症状不要写进现病史，放到 negatives 数组。
- 对话里信息不足以填写的条目，列进 unclear_points 数组。

## 除字段列表外，额外输出两项

{
  "negatives": ["有鉴别意义的阴性所见"],
  "unclear_points": ["信息不足、无法填写的条目"]
}
